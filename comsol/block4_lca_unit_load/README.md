# 블록 4 · 로어암 단위하중 해석 (담당 B, COMSOL)

**시작 전 필수 확인: D7 (COMSOL 라이선스 — Structural Mechanics 모듈, LiveLink for MATLAB 유무).**
선배 팀이 라이선스/구버전(5.2) 제약을 겪은 사례 있음. `docs/decisions.md` 참고.

## 핵심 방법

과도해석 대신 **정적해석 3–4회**(볼조인트 Fx,Fy,Fz 각 1N, 필요시 액추에이터 마운트 1N)만 수행 → 핫스팟
응력계수 표 생성. 제어기를 바꿔도 COMSOL 재해석 불필요 — Fatigue Module 없이 가능.

- 전제: 선형탄성 + 준정적 → 로어암 1차 고유진동수가 노면 가진 대역보다 충분히 높아야 함 (고유진동수 해석으로 증명)
- 형상: COMSOL에서 **파라메트릭으로 직접 모델링** (두께 등 스윕 가능). CAD import는 선배 팀 두 번 실패 사례 있음 — 피할 것
- 경계조건: 부싱은 Fixed 대신 **Spring Foundation**(과구속 응력집중 방지). 볼조인트 하중은 **Rigid Connector**로
  분산(cae7의 선하중 과응력 문제 회피)
- 검증: 메쉬 수렴(핫스팟 응력 변화 기준), 곡선빔 해석해와 비교(cae1 방식)

## 재질 (D4, OPEN)

단조 알루미늄 vs 강판 — S-N 데이터를 실제로 확보할 수 있는 쪽으로 결정해야 함. 이게 안 정해지면 블록 5(피로)로
못 넘어감.
