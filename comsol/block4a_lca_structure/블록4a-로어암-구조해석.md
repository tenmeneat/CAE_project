# 블록 4a · 로어암 구조 해석 (담당 B, COMSOL)

**시작 전 필수 확인: D7 (COMSOL 구성 — Structural Mechanics 모듈 있음, AC/DC 모듈 없음 확인됨[v0.8].
버전과 Rigid Connector 기능 유무는 W1–W3에 실제로 확인).**

## 핵심 방법

과도해석 대신 **정적해석 3–4회**(볼조인트 Fx,Fy,Fz 각 1N, 필요시 마운트 1N)만 수행 → 핫스팟 응력계수 표
생성. 제어기를 바꿔도 COMSOL 재해석 불필요 — Fatigue Module 없이 가능.

- 전제: 선형탄성 + 준정적 → 로어암 1차 고유진동수가 노면 가진 대역보다 충분히 높아야 함 (고유진동수 해석으로 증명)
- 형상: COMSOL에서 **파라메트릭으로 직접 모델링** (두께 등 스윕 가능). CAD import는 쓰지 않음 — 선배 팀 두 번
  실패 사례 있음, import한 형상은 파라미터 연결이 끊겨 두께 스윕이 어려움
- 경계조건: 부싱은 Fixed 대신 **Spring Foundation**(과구속 응력집중 방지). 볼조인트 하중은 **Rigid
  Connector**로 분산(cae7의 선하중 과응력 문제 회피) — Structural Mechanics Module 기능이므로 **실제로
  쓰이는지 W3에 확인하고, 안 되면 Boundary Load 분포 또는 고강성 인서트 도메인으로 대체**
- 검증: 메쉬 수렴(핫스팟 응력 변화 기준), 곡선빔 해석해와 비교(cae1 방식). **Beam 인터페이스 — 빔 모델을
  더해 솔리드·빔·해석해 3중 비교**

## 마운트 위치 p (v0.8, 블록 3과 공유하는 설계 변수)

- **설계 기준 로어암은 앞 1개.** 응력 지표는 네 코너 모두 계산하지만(행렬 곱이라 비용 거의 없음), DEL이 가장 큰
  코너를 설계 기준 코너로 삼는다. 가설: 강한 제동 후 선회 코너의 앞 바깥쪽(예: La Source 진입 시 앞 왼쪽)이
  가장 혹사됨. 뒤 코너는 같은 모델로 참고만 계산하며 리어 p는 고정(D18).
- **단위하중 해석은 프런트 마운트 위치 p 3수준마다 반복**(약 9–16회). 두께 스윕과 같은 형식으로 함께 실행.

## 재질 (D4, OPEN)

단조 알루미늄 vs 강판 — 상대 지표(R, DEL)라 σ'f 정밀도 요구는 낮지만 인장강도 σu와 S-N 지수 m의 문헌 범위가
필요. 이게 안 정해지면 블록 5(응력 지표)로 못 넘어감.

## 허용 응력 / 최소 단면 (D11, D12 — 메인 결과)

**허용 응력은 시뮬레이션 결과가 아니라 설계 기준이다.** 재료 강도를 안전계수로 나눈 값으로 D4(재질)와
D12(안전계수)가 정하고, 시뮬레이션이 내놓는 것은 실제 부하 응력(핫스팟 피크, DEL)이다. 둘을 비교해서 로어암
최소 단면을 구한다 — **정적해석 약 9–16회 재해석 필요**.

## 단위하중 정의 (블록 3과 합의, 2026-11-04)

블록 3 노트 11절의 **(나)안**: 스트럿 마운트를 스트럿 축 `u_s` 방향 지지로 두고 LBJ에 로컬 단위하중 3개
(`BJ_x`, `BJ_y`, `BJ_z`, 각 1 N). 부싱 2점은 Spring Foundation. 이렇게 하면 마운트 반력이 블록 3의 `F_M`과
자동으로 같아지고(같은 힌지축 모멘트 평형), 블록 5는 `F_BJ`(로컬 3성분)만 곱하면 된다.

좌표는 **로어암 로컬** (원점 LCA_F, e1 = 힌지축 전방, e2 = 바깥, e3 ≈ 위), `lca_unit_load_spec(hc, p)`가 낸다.

## 응력계수 표 C 형식 (4a → 5)

CSV 한 행 = p × 하중 케이스 × 핫스팟: `p,load_case,hotspot,s11,s22,s33,s12,s23,s13` — 로어암 로컬 좌표 응력텐서,
**단위 [Pa/N]**. `write_stress_coeffs_csv` / `read_stress_coeffs_csv`(MATLAB, `matlab/block4a_lca_structure`).
COMSOL에서 핫스팟 점의 응력 6성분을 이 형식으로 내보내면 블록 5가 그대로 읽는다(`lca_damage`의 `opts.C_front`).

## MATLAB 쪽과 해석해 대용 (2026-11-04)

**D7 확인 (2026-11-04)**: 이 PC의 COMSOL은 5.2(Multiphysics, **LiveLink for MATLAB 없음**)와 6.4 **Client**뿐이라
MATLAB에서 COMSOL을 직접 돌릴 수 없다 → COMSOL은 GUI로 돌리고 위 CSV로 내보내는 경로로 간다.

COMSOL 표가 나오기 전까지 블록 5를 끝까지 돌리려고 **A형 암 등가 빔 해석해** `stress_coeffs_beam`을 만들었다. 이 값은
COMSOL이 나오면 4a 검증의 "곡선빔 해석해"(솔리드·빔·해석해 3중 비교)로 쓴다.

- 축 r_foot → LBJ (길이 L = 0.386 m), 앞·뒤 부재는 같은 사각 중공 단면 `lca_section` **[가정] 50 × 35 mm, 벽 5 mm**,
  부재 간격 w(s) = w0·(1 − s/L), w0 = 0.400 m.
- 힌지축 둘레 회전 자유(수직 굽힘 0), 면내 굽힘은 두 부재의 짝힘, 마운트는 `u_s` 방향 지지(반력 = `F_z/(p·u_s3)` =
  블록 3 `F_M`, 테스트로 일치 확인).
- 핫스팟 8개: {마운트 단면 M, 뿌리 R} × {앞 F, 뒤 B 부재} × {위 T, 아래 U}, 모서리 섬유라 σ22(축 방향)만 0이 아니다.
- 마운트 단면 아래 섬유 수직 1 kN당 13.3 / 9.3 / 5.3 MPa (p = 0.50 / 0.65 / 0.80) — 설계안의 `M = F·(1−p)·L` 관계.

| 파일 | 역할 |
|---|---|
| `lca_section.m` | 대용 단면 [가정], 두께 스윕 변수 `tw` |
| `lca_unit_load_spec.m` | COMSOL 입력 좌표·하중 케이스 (위 표) |
| `stress_coeffs_beam.m` | 해석해 응력계수 표 C |
| `write_stress_coeffs_csv.m`, `read_stress_coeffs_csv.m` | 4a → 5 CSV |
| `test_stress_coeffs.m` | 굽힘 손계산, 힌지 굽힘 0, 면내 트러스 근사, 반력 = 블록 3 F_M, CSV 왕복 |
