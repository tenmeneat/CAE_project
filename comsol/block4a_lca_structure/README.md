# 블록 4a · 로어암 구조 해석 (담당 B, COMSOL)

**시작 전 필수 확인: D7 (COMSOL 구성 — Structural Mechanics 모듈 있음, AC/DC 모듈 없음 확인됨[v0.8].
버전과 Rigid Connector 기능 유무는 W1–W3에 실제로 확인).**

## 핵심 방법

과도해석 대신 **정적해석 3–4회**(볼조인트 Fx,Fy,Fz 각 1N, 필요시 마운트 1N)만 수행 → 핫스팟 응력계수 표
생성. 제어기를 바꿔도 COMSOL 재해석 불필요 — Fatigue Module 없이 가능.

- 전제: 선형탄성 + 준정적 → 로어암 1차 고유진동수가 노면 가진 대역보다 충분히 높아야 함 (고유진동수 해석으로 증명)
- 형상: COMSOL에서 **파라메트릭으로 직접 모델링** (두께 등 스윕 가능). CAD import는 쓰지 않음 — 선배 팀 두 번
  실패 사례 있음, import한 형상은 파라미터 연결이 끊겨 두께 스윕이 어려움
- 경계조건: 부싱은 Fixed 대신 **Spring Foundation**(과구속 응력집중 방지). 볼조인트 하중은 **Rigid
  Connector**로 분산(cae7의 선하중 과응력 문제 회피) — Structural Mechanics Module 기능이므로 **실제로
  쓰이는지 W3에 확인하고, 안 되면 Boundary Load 분포 또는 고강성 인서트 도메인으로 대체**
- 검증: 메쉬 수렴(핫스팟 응력 변화 기준), 곡선빔 해석해와 비교(cae1 방식). **Beam 인터페이스 — 빔 모델을
  더해 솔리드·빔·해석해 3중 비교**

## 마운트 위치 p (v0.8, 블록 3과 공유하는 설계 변수)

- **설계 기준 로어암은 앞 1개.** 응력 지표는 네 코너 모두 계산하지만(행렬 곱이라 비용 거의 없음), DEL이 가장 큰
  코너를 설계 기준 코너로 삼는다. 가설: 강한 제동 후 선회 코너의 앞 바깥쪽(예: La Source 진입 시 앞 왼쪽)이
  가장 혹사됨. 뒤 코너는 같은 모델로 참고만 계산하며 리어 p는 고정(D18).
- **단위하중 해석은 프런트 마운트 위치 p 3수준마다 반복**(약 9–16회). 두께 스윕과 같은 형식으로 함께 실행.

## 재질 (D4, OPEN)

단조 알루미늄 vs 강판 — 상대 지표(R, DEL)라 σ'f 정밀도 요구는 낮지만 인장강도 σu와 S-N 지수 m의 문헌 범위가
필요. 이게 안 정해지면 블록 5(응력 지표)로 못 넘어감.

## 허용 응력 / 최소 단면 (D11, D12 — 메인 결과)

**허용 응력은 시뮬레이션 결과가 아니라 설계 기준이다.** 재료 강도를 안전계수로 나눈 값으로 D4(재질)와
D12(안전계수)가 정하고, 시뮬레이션이 내놓는 것은 실제 부하 응력(핫스팟 피크, DEL)이다. 둘을 비교해서 로어암
최소 단면을 구한다 — **정적해석 약 9–16회 재해석 필요**.
