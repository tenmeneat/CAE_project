# 블록 1 · 랩 시뮬레이션 (담당 A, MATLAB)

준정상(Quasi-Steady-State) 랩 시뮬. 서킷 곡률·고저 → `v(t), ax(t), ay(t)`. **v0.8: 시나리오 A/B 둘 다 이 블록에서
만든다** — 같은 서킷 데이터에서 속도 프로파일만 두 번 만들고 전처리(I0)는 추가로 돌리지 않는다.

입력: TUMFTM 레이스라인 CSV + 인터페이스 I0 (`fastf1_<track>.csv`, 고저/검증용)
출력: 블록 2(Simulink)로 넘기는 시간축 하중 입력 (시나리오 태그 `<scn>` 포함)

## 시나리오 A/B (v0.7 확정)

| | 시나리오 A · 스포츠 | 시나리오 B · 컴포트 |
|---|---|---|
| 경로·속도 | Spa **레이스라인**, 마찰원 한계까지 주행 | Spa **중심선**, 가속도 상한 \|ay\|≤0.4g, \|ax\|≤0.3g (D17) |
| 노면 | 고저 + ISO 8608 B-C급 | 고저 + ISO 8608 B-C급 |

시나리오 B는 레이스라인이 아니라 중심선을 쓰고, 속도는 한계 주행이 아니라 가속도 상한으로 제한한다(검증
체크리스트 v0.7: 시나리오 B 속도 프로파일이 상한을 지키는지 확인).

## 처리 순서 (4.1절)

1. 레이스라인/중심선 Δs=1m 재샘플 → 수평 곡률 κ(s) (중심선이 아니라 레이스라인 곡률을 써야 속도가 맞음 — A에만 해당)
2. FastF1 Z를 s 기준 정렬·평균·평활 → 고저 z(s), 경사 θ(s), 수직 곡률 κv(s)
3. 코너 한계속도 `v_lim(s) = sqrt(mu*g/|κ(s)|)` (시나리오 A)
4. 전진 적분(파워·트랙션 한계) + 후진 적분(제동 한계), 마찰원(ax ≤ ax,max·sqrt(1-(ay/ay,max)^2)) 결합 (시나리오 A).
   시나리오 B는 상한값으로 직접 캡.
5. s→t 변환 후 v(t), ax(t), ay(t) 출력. 고저 위에 ISO 8608 랜덤 노면(B-C급) 중첩 (R6)

차량 기준: BMW F82 M4급 (액티브 서스펜션은 가정 추가, 4.2절 참고). F1은 액티브 서스펜션 금지라 부적합.

## 검증 (빠뜨리면 안 됨 — W2 게이트)

- 방법론 검증: F1급 파라미터로 돌린 v(s)를 FastF1 실측과 비교
- 차급 검증: GT 파라미터 랩타임이 실측 ±10% 이내인지
- **v0.7 신규**: 시나리오 B 속도 프로파일이 가속도 상한(\|ay\|≤0.4g, \|ax\|≤0.3g)을 지키는지

  고저 평균
