# 블록 3 · 휠력 → 로어암 하중 변환 (담당 B, MATLAB, 준정적 FBD)

하드포인트(볼조인트, 부싱 2개, 스프링/액추에이터 마운트, 타이로드 등) 좌표 기반으로 너클 자유물체도 구성 →
선형 연립방정식으로 볼조인트·부싱 반력 계산.

- 가정: 링크 질량 무시, 준정적, 미소 변위(하드포인트 고정)
- 입력: I1 (`wheel_forces_<track>_<ctrl>.mat`)
- 출력: 시간별 로어암 하중 벡터 `F_LCA(t)` (볼조인트 Fx,Fy,Fz + 액추에이터 마운트 힘)
- 검증: 대표 하중 1케이스 손계산과 대조

## 주의

세부 설계(미지수·방정식 구성)는 **D1(서스펜션 형식) 확정 후** 작성 가능 — `docs/decisions.md` 참고.
설계안 추천값은 더블위시본(스프링·액추에이터 로어암 마운트).
