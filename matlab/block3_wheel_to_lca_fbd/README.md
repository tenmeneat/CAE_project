# 블록 3 · 휠력 → 로어암 하중 변환 (담당 B, MATLAB, 준정적 FBD)

서스펜션 형식(더블위시본, D1)은 확정. 아래 구성은 **W1에 팀이 검토해 확정**.

- **하드포인트**: 상·하부 볼조인트, 로어암 부싱 2점, 상부암 부싱 2점, 스프링·액추에이터 마운트(로어암),
  타이로드 내·외측 좌표를 표로 정리. 출처는 문헌값 또는 공개 사양(D3). **프런트 액추에이터 마운트는 로어암
  위 3수준 p(바깥·중간·안쪽, D16)로 두고 FBD를 p별로 구성. 리어 마운트는 패키징 기준 고정 1점(D18, 가정).**
- **입력**: 휠센터력 `(Fx,Fy,Fz)_i`, 액추에이터 힘 `F_act,i`, 스프링·댐퍼 힘 (블록 2).
- **모델(초안)**: 상·하부 위시본은 부싱 2점으로 부재 둘레로 회전하는 링크, 타이로드는 축력만 받는 2력 부재로
  가정. 너클+휠 자유물체도 6개 상하부암(외력 없음)과 하부암(스프링·액추에이터 힘 작용)의 힌지축 모멘트
  평형을 더해 볼조인트·타이로드 반력을 구함.
- **W1 점검 항목**: (a) 미지수와 방정식 개수를 세어 과구속·부정정 여부 확인. 부정정이면 부싱을 스프링
  요소로 두고 변형 적합 조건을 추가. (b) 블록 2가 내놓는 휠력과 서스펜션 상대속도가 너클 평형을 만족하는지
  잔차 확인.

## 마운트 위치 p의 영향과 결정 절차 (v0.8)

힌지축 모멘트 평형으로 단순화한 관계 (암 각도 α 무시). 볼조인트에 휠 힘 `F_wheel`이 작용할 때
`F_act * p * L = F_wheel * L`.

| 항목 | 관계 | p 증가 (볼조인트 쪽) | p 감소 (힌지 쪽) |
|---|---|---|---|
| 액추에이터 힘 | `F_act = F_wheel / p` | 감소 | 증가 → 포화 위험 |
| 코일 줄열 | ∝ F_act² | 감소 | 급증 |
| 액추에이터 위치의 암 굽힘 | `M = F_wheel*(1-p)*L` | 감소 | 증가 |
| 필요 스트로크·속도 | ∝ 1/p | 증가 | 감소 |
| 패키징 | — | 휠·브레이크·타이로드 간섭 위험 | 여유 |

1. `p_max`: 하드포인트로 패키징 가능한 가장 바깥 위치와 액추에이터 스트로크 한계로 정함.
2. `p_min`: 휠 기준 필요 최대 힘 `F_wheel,max`를 액추에이터 포화 한계 `F_sat,act`로 나눈 값
   (`F_wheel,max / F_sat,act`)보다 크게 정함. 이보다 작으면 상시 포화.
3. **3수준**: `[p_min, p_max]`를 3등분. 임시값 0.5/0.65/0.8은 **근거 없는 가정**이며 D3(하드포인트)·D15(포화
   기준)가 정해지면 폐기 → **D16**.
4. **리어**: 패키징 기준값 1개로 고정(D18). 리어 액추에이터의 힘·스트로크·열 한계 환산에는 계속 사용.

출력: 시간별 로어암 하중 벡터 `F_LCA(t)` (볼조인트 Fx,Fy,Fz + 스프링·액추에이터 마운트 힘).

## 가정

링크 질량 무시, 준정적, 미소 변위(하드포인트 고정).

## 검증

대표 하중 1케이스 손계산과 대조.
