## 1. 좌표·부호 규약

- 좌표계: ISO 8855 차량 좌표(x 전방, y 좌측, z 상방). 원점은 **앞 차축 중심 바로 아래 지면**.
- 코너 순서: FL → FR → RL → RR (인덱스 1–4).
- **좌측 등가 좌표**: 우측 코너(FR, RR)는 y를 반전해 좌측 코너처럼 계산한다. 하드포인트는 `y → −y`, 입력 힘은
  `Fy → −Fy`로 바꾼다. 출력도 좌측 등가 좌표로 낸다 → COMSOL 모델(앞 왼쪽 로어암 1개)과 응력계수 표 하나로 네
  코너를 모두 처리한다.
- 힘의 주체:
  - `F_L`, `F_U`: 로어암·상부암이 **너클에** 주는 힘. 로어암이 받는 힘은 `−F_L`.
  - `f_T`: 타이로드 축력. **인장 +**.
  - `F_s`: 스트럿 축력. **압축 +**. 로어암에는 `−F_s·u_s`가 걸린다(`u_s`: 로어암 마운트 → 차체 상부 마운트 단위벡터).
- 타이어 힘 `Fx, Fy, Fz`: 지면이 타이어에 주는 힘(ISO 8855). `Fz`는 정적 하중을 포함한 절대값, 접지 +.

## 2. 정식화 — 너클 FBD를 8×8 선형 문제로

미지수 `x = [F_L(3); F_U(3); f_T; F_s]` (8개).

| 식 | 개수 | 내용 |
|---|---|---|
| 너클+휠 힘 평형 | 3 | `F_L + F_U + f_T·u_T + F_ext = 0` |
| 너클+휠 모멘트 평형 (기준점: 휠센터) | 3 | `r_L×F_L + r_U×F_U + r_TO×f_T·u_T + M_ext = 0` |
| 상부암 힌지축 모멘트 | 1 | `e_U · ((r_UBJ − r_UCA_F) × (−F_U)) = 0` (상부암에는 외력 없음) |
| 하부암 힌지축 모멘트 | 1 | `e_L · ((r_LBJ − r_LCA_F) × (−F_L) + (r_M − r_LCA_F) × (−F_s·u_s)) = 0` |

`A(hp, p)·x(t) = b(t)`. **A는 하드포인트와 p로만 정해진다**(미소 변위). 그래서 코너·p마다 한 번 분해하고 `X = A \ B`로
시간축 전체를 한 번에 푼다. 영향 행렬 `T = A⁻¹·G`(8×6, `G`는 외력 → b 사상)를 출력해 블록 5가 하중 성분을 나눠
통과시킬 수 있게 한다(응력 기여 분해 `res.parts`).

### 우변 b(t) — 외력의 작용점

| 성분 | 작용점 | 이유 |
|---|---|---|
| `Fz`, `Fy` | 접지점 CP | 타이어 힘 |
| `Fx < 0` (제동) | **접지점 CP** | 캘리퍼가 너클에 달려 있어 제동 토크를 너클이 받음 → 접지점 높이 모멘트가 그대로 걸림 |
| `Fx > 0` (구동, 후륜만) | **휠센터 WC** | 구동 토크는 하프샤프트→디퍼렌셜이 받음 → 너클에는 휠센터에 힘만. F82는 후륜구동이라 **프런트에는 구동 Fx가 없다** |
| `−m_u·(g + z̈_u)` | 휠센터 WC | 비현가 질량 자중 + 달랑베르 관성. 이게 없으면 휠홉 대역(10–15 Hz)에서 블록 2의 스프링·댐퍼 힘과 안 맞음 |

`F_ext = F_cp + F_wc`, `M_ext = (r_CP − r_WC)×F_cp`. 접지점 `r_CP = r_WC − [0 0 r_w]`.

## 3. 마운트 위치 p와 모션비 MR(p)

- **p 정의 [가정, D16에 기록]**: 하부 볼조인트(LBJ)를 하부암 힌지축에 수선으로 내린 발 `r_foot`을 0, LBJ를 1로 하는
  비율. 마운트점 `r_M = r_foot + p·(r_LBJ − r_foot)`.
- **스트럿 축 [가정]**: p가 바뀌어도 스트럿 경사각 α(수직에서 안쪽으로)는 고정. 상부 마운트가 p를 따라 평행이동.
- **MR(p) 정의**: 접지점에 수직 단위하중만 걸 때 `MR = Fz / F_s`(정역학). 기구학 정의(`MR = dL_strut / dz_cp`)와 가상일로
  같아야 한다 → 테스트 항목. **MR은 이 블록이 하드포인트에서 계산해 블록 2에 넘긴다**(포화·스트로크 환산, 스프링 강성
  ∝ 1/MR²). 두 블록이 같은 MR을 쓰게 하려는 것.
- **p의 영향** (설계안 4.3절, 힌지축 모멘트 평형 단순화):

| 항목 | 관계 | p 증가 (볼조인트 쪽) | p 감소 (힌지 쪽) |
|---|---|---|---|
| 액추에이터 힘 | `F_act = F_wheel / MR ≈ F_wheel / p` | 감소 | 증가 → 포화 위험 |
| 코일 줄열 | ∝ F_act² | 감소 | 급증 |
| 마운트 위치의 암 굽힘 | `M = F_wheel·(1−p)·L` | 감소 | 증가 |
| 필요 스트로크·속도 | ∝ MR ≈ p | 증가 | 감소 |
| 패키징 | — | 휠·브레이크·타이로드 간섭 위험 | 여유 |

- **D16 지원**: `mr_curve(p_grid)`로 p ∈ [0.3, 0.95]의 MR 곡선을 내고, `p_min`은 `MR(p_min) ≥ F_wheel,max / F_sat,act`
  조건으로 정한다(설계안 4.3절).

## 6. 출력 `F_LCA`

| 필드 | 크기 | 의미 | 소비처 |
|---|---|---|---|
| `t`, `s` | N×1 | I1에서 그대로 | |
| `F_BJ` | N×3×4 | LBJ에서 **로어암이 받는 힘** `−F_L`, **로어암 로컬 좌표** [N] | 4a 단위하중, 5 중첩, 뷰어(I3) |
| `F_M` | N×4 | 마운트에서 로어암이 받는 스트럿 힘 크기(압축 +). 방향은 `u_s_loc` | 4a, 5 |
| `u_s_loc` | 3×4 | 스트럿 단위벡터(로컬 좌표) | 4a 하중 방향 |
| `F_act_act` | N×4 | **액추에이터 실제 힘** `= F_act / MR` | 4b 열, 6 사양표 |
| `resid_Fs` | N×4 | `F_M − (F_spring + F_damper + F_act)/MR` | 검증(설계안 W1 (b)) |
| `MR` | 1×4 | 이 블록이 계산한 모션비 | 블록 2 |
| `F_UBJ`, `f_T` | N×3×4, N×4 | 진단용 | 손계산 대조 |
| `T` | 8×6×4 | 영향 행렬 `x = T·[F_cp; F_wc]` | 블록 5 `res.parts` |
| `Rloc`, `meta` | 3×3×4, struct | 로컬 축, `p`, `scn`, `ctrl`, 하드포인트 버전 | |

**로어암 로컬 좌표** (좌측 등가, 원점 `LCA_F`): `e1` = 힌지축 전방(`LCA_R → LCA_F`), `e2` = 바깥쪽(`r_foot → r_LBJ`를
`e1`에 직교화), `e3 = e1 × e2`(≈ 위). COMSOL 모델을 같은 축으로 만든다(4a와 합의).

## 8. 더미 I1 — 블록 2 없이 지금 돌리기

`make_dummy_i1(scn)`: 블록 1 `lap_sim` 출력(`t, v, ax, ay, s`)을 dt = 0.01 s 등간격으로 리샘플한 뒤 4절 스키마로 채운다.

- `Fz_i` = 정적 + 종방향 하중이동(`m·ax·h_cg/L`, 앞뒤 ±½) + 횡방향 하중이동(`m·ay·h_cg/t`, 앞뒤 배분 `lltd_f = 0.57` — 블록 2와 같은 값, 병합 전 임시값은 0.55).
  `m`, `h_cg`, `L`은 `f82_params()`에서 읽는다.
- `Fy_i = m·ay · Fz_i/ΣFz`. `Fx`: 제동은 `Fz` 비례, **구동은 후륜 둘에만**.
- 선택: ISO 8608 성분을 쿼터카 전달함수로 `Fz`에 더함(`opts.road = true`). 기본은 끔.
- `F_spring = Fz − m_u·g`, `F_damper = F_act = 0`(Passive 준정적), `zdd_u = 0`, `ctrl = 'dummy_qs'`.

이걸로 확인할 것: Spa 1랩 `F_BJ`의 크기, 설계 기준 코너 가설(La Source 진입 앞 왼쪽), `resid_Fs`로 본 재킹 크기.

## 9. 검증

프로토타입(Python, 5절 임시 하드포인트)으로 미리 계산한 기대값:

| p | cond(A) | MR 정역학 | MR 기구학 | p·cosα |
|---|---|---|---|---|
| 0.50 | 19.0 | 0.4940 | 0.4940 | 0.495 |
| 0.65 | 18.5 | 0.6423 | 0.6423 | 0.644 |
| 0.80 | 18.5 | 0.7905 | 0.7905 | 0.792 |

p = 0.65, 앞 코너 정적 하중 `Fz0 = 1642·0.523·9.81/2 = 4,212 N`:

| 케이스 | 로어암이 받는 LBJ 힘 (차량 좌표) [N] | F_s [N] | Fz/MR [N] | 차이 |
|---|---|---|---|---|
| 정적 | (0, 805, 4,131) | 6,558 | 6,558 | 0 |
| 제동 1 g, 바깥 앞 (Fz 1.6·Fz0) | (−9,053, 3,724, 6,591) | 10,358 | 10,494 | −1.3% (anti-dive) |
| 우선회 1 g, 앞 왼쪽 (Fz 1.5·Fz0) | (0, −7,218, 6,409) | 9,314 | 9,837 | −5.3% (롤센터 재킹) |

→ 블록 2는 anti-dive·롤센터를 무시하므로 `resid_Fs`가 0이 아닌 것이 정상이다. **크기를 보고서에 적는다.**
제동에서 로어암 종방향 하중(약 9 kN)이 수직(6.6 kN)보다 크다 → 함정 1(수평력)이 실제로 지배적임을 확인.

테스트 (`assert` 기반, 블록 1 방식):

1. 정적 수직하중: `F_s = (Fz − m_u·g)/MR` (1e-6 상대오차). `m_u = 0`으로 두면 위 표의 값이 그대로 나와야 함.
2. 2D 지렛대 손계산: `F_s ≈ Fz/(p·cosα)` 5% 이내 (설계안 4.3절 관계).
3. MR 정역학 = MR 기구학 (가상일, 1e-6).
4. 너클 평형 잔차 `‖A·x − b‖ < 1e-9·‖b‖`, `cond(A) < 1e3`.
5. 좌우 대칭: 같은 크기의 좌선회·우선회에서 FL과 FR의 좌측 등가 출력이 같음.
6. 정지 상태 더미 I1: 네 코너 `Fz` 합 = `m·g`, `resid_Fs = 0`.

- 블록 2 `Fz`에는 노면 고저(압축 구간)가 들어가지만, 매끈한 노면에서도 Raidillon이 최대이고 그 지점 FL의 수평력/`Fz`는
  **1.28로 여전히 μ = 1.10을 넘는다.** 블록 1 가속도(압축 그립 이득 `gn_max` 포함)와 블록 2 동적 `Fz`가 서로 맞지 않는
  구간이라, 설계 기준 코너 가설은 **아직 판정하지 않는다.** 블록 1·2 사이 그립 일관성(코너별 마찰 사용률 ≤ μ)을 먼저
  맞춰야 한다.
- 남은 잔차는 블록 2가 무시하는 anti-dive·롤센터 재킹(FBD는 반영)이다. 휠홉 대역의 큰 오차는 없었다(`zdd_u` 포함).

**설계와 다르게 하거나 정한 것**

- 우측 코너 하드포인트는 좌측 등가 좌표라 좌측과 같은 값을 쓴다. 접지점 `CP`는 `hardpoints_f82`가 `block3_params().r_w`로
  만든다(`build_fbd_matrix(hc, geo)` 시그니처를 지키려고).
- `wheel_load_vector`는 Fx를 부호로만 나눈다(음수 → 접지점, 양수 → 휠센터). 프런트에 Fx > 0이 들어오면 경고만 낸다.
- `F_UBJ`는 상부암이 받는 힘 `−F_U`이며 차량(좌측 등가) 좌표다. `F_M`이 로어암에 주는 힘은 `−F_M·u_s_loc`.
- 더미 I1의 Fx 합에 공기저항 `½ρC_dA·v²`를 더했다(설계 8절은 `m·ax`만 언급). 횡방향 하중이동은 앞뒤 트레드를 따로 쓴다.
  바퀴가 들리면 `Fz = 0`으로 자르고 경고.
- `make_dummy_i1`의 `opts.road`(ISO 8608 성분)는 **미구현**: 쿼터카 파라미터(스프링·댐퍼·타이어 강성)가 D3에서 정해지지
  않았다. 호출하면 에러.
