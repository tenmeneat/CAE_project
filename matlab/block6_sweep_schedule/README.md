# 블록 6 · 마운트 위치·시나리오·제어 스윕 + 2단계 선정 (담당 A, MATLAB)

## 스윕 (v0.7)

프런트 마운트 위치 p(3수준) × 시나리오(A, B) × 제어 설정(LQR Q/R 가중치 격자, Skyhook, Passive, 위치
스케줄 LQR) ≈ **약 300–480회**. 각 조합마다 블록 2 → 3 → 5를 자동 실행(CAE06 구조 참고). 격자와 임계값은
D14로 W1에 승인·고정한다.

## 3축 지표 계산

- **성능 A** (타이어 동하중 RMS) / **B** (ISO 2631-1 가중 승차감), 액추에이터 부담(RMS·피크 힘, 평균 소비전력,
  열 여유 `F_rms/F_th` — I5 입력), 로어암 응력(I2가 돌려주는 피크 응력·DEL·R)
- 접지는 두 시나리오 모두 항상 보고. 제약을 위반한 조합은 표시만 하고 후보에서 제외(5.2절)

## 결과: 메인 결과물

**시나리오별 3축 트레이드오프 그림 2장** + **마운트 위치 비교 그림 1장**이 메인 결과. 최적 선정은 5.4절
2단계 규칙.

## 최적 선정 규칙 (2단계, 5.4절)

1. **모드별 제어 설정**: 마운트 위치 p마다, 시나리오별로 ε-제약(해당 시나리오 제약 모두 만족 + 액추에이터
   예산 Pmax 이하) 후보 중 **로어암 DEL이 최소**인 설정 1개를 고른다.
   - 보조: 파레토 무릎점(가로축 액추에이터 RMS 힘, 세로축 로어암 DEL, 색=성능 지표)으로 그려 액추에이터를
     더 키워도 이득이 거의 늘지 않는 지점을 표시
   - 가중합(임의 가중치)은 근거가 약해 **민감도 확인용으로만** 사용
2. **마운트 위치 p\***: 두 시나리오 모두 1단계 선정을 만족하는 p 중, **시나리오 A의 로어암 DEL이 최소**인 p를
   고른다. 모드별 최적 위치가 다르면 그 차이 자체를 결과로 보고한다(하드웨어 1개의 타협점). 선택: 사용 비율
   가중(예: 컴포트 90%/스포츠 10%)으로 손상을 혼합 평가하는 것은 민감도로만 제시.

결과의 모양은 시뮬레이션 전에는 모른다. 액추에이터가 로어암에 마운트되어 있어 힘이 커질수록 로어암 굽힘하중이
직접 늘지만 휠 하중 변동은 줄 수 있다. 로어암 DEL이 최소점을 가진 U자 형태로 나오면 그 최소점이 곧 최적이고,
단조 감소로 나오면 예산 제약이나 무릎점이 최적을 정한다. 어느 쪽이든 연구질문으로 성립한다.

## 위치 스케줄 제어 (메인 기여 후보, D2)

고하중 구간(Eau Rouge 등)은 접지·하중 가중치, 직선은 승차감 가중치. 고정 LQR 대비 3축 모두 나은지 비교.
**주의**: 게인을 순간 전환하면 과도응답 자체가 하중 스파이크가 됨 → 거리 s 기준으로 게인을 블렌딩(보간).

## 액추에이터 요구 사양 후처리

각 제어기의 `F_act(t)`, 스트로크, 상대속도에서 피크·RMS 힘, 최대 스트로크·속도, 필요 대역폭(힘 스펙트럼),
피크·평균 소비전력(기계 일률 + 줄열 I²R)과 `Fth` 대비 여유를 표로 정리 → **질문 2의 답**.
