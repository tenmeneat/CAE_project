# 블록 6 · 제어 가중치 스윕 + 위치 스케줄 제어 (담당 A, MATLAB)

- LQR Q/R 가중치 스윕(CAE06 구조 참고) → 각 조합마다 블록 2 → 3 → 5를 자동 실행 (COMSOL 재해석은 불필요,
  C 응력계수 표는 고정값으로 재사용)
- 결과: **승차감(차체 가속도 RMS) vs 랩당 로어암 손상 파레토 곡선** = 메인 결과 그래프
- 위치 스케줄 제어: 고하중 구간(Eau Rouge 등)은 접지·하중 가중치, 직선은 승차감 가중치. 고정 LQR 대비 손상·승차감
  둘 다 개선되는지 비교
- **주의**: 게인을 순간 전환하면 과도응답 자체가 하중 스파이크가 됨 → 거리 s 기준으로 게인을 **블렌딩(보간)**
