# 블록 2 · 풀카 7자유도 + 액티브 제어 (담당 A, Simulink)

실제 F82의 댐퍼는 연속 가변(EDC, 세미액티브)이고 액티브 서스펜션은 없다. **이 차급에 액티브를 얹었을 때를
가정**한다 — 발표에서 "M4급 후륜 고성능 쿠페 + 일반 더블위시본" 전제로 명시.

## 구현 방식

- MATLAB에서 `A, B` 행렬을 만들고 Simulink **State-Space 블록**으로 구현 (대수루프 원천 차단, cae5가 겪은 문제
  회피). 같은 `A, B`를 `lqr()`에 그대로 사용.
- 상태: 7DOF → 14개(변위+속도), 액추에이터 1차 지연 포함 시 +4
- 입력: 액추에이터 힘 4개(FL,FR,RL,RR) + 노면 변위 4개. **스프링 강성과 액추에이터 포화 한계는 앞뒤를 따로 둔다.**
  후륜 노면 입력은 τ=L/v 지연.
- 수평 하중 얹기(함정 1 대응): pitch 모멘트 `M_θ = m_s*ax*h_cg`, roll 모멘트 `M_φ = m_s*ay*h_cg`를 차체에 인가.
  타이어 Fx,i/Fy,i는 Fz,i 비례 분배. anti-dive·롤센터 효과는 무시(가정으로 명시).
- 제어기 4종: Passive / Skyhook(기준선) / LQR(승차감·접지 가중치) / 위치 스케줄 LQR (→ 블록 6)

## 액추에이터 현실성 (D15)

- 포화 + 1차 지연(대역폭) 반영. 기준값은 양산 액티브 서스펜션 공개 수치(**Audi A8: 포화 약 3.7kN·뒤 약
  3.3kN, 대역폭 0–6Hz, 힘 증가율 16kN/s에서 출발[R17]**) — 이 값이 액추에이터 기준인지 휠 기준인지 **출처에서
  확인해야 함(D15)**, 포화는 p별 모선비로 휠 기준 환산해 적용(4.3절, 아래 참고).

## 프런트 마운트 위치 p (v0.8, 블록 3·4a와 공유하는 설계 변수)

마운트가 안쪽일수록 모선비 MR이 작아져 같은 휠 힘에 필요한 액추에이터 힘이 커진다
(`F_act = F_wheel/MR`, 스프링 강성 환산은 ∝ 1/MR²). **포화·스트로크·속도 한계는 액추에이터 기준이므로**
휠 기준으로 환산해 이 블록에 적용한다: `F_sat,wheel = MR(p) * F_sat,act`, 휠 스트로크·속도 한계 =
액추에이터 한계 / MR(p). 따라서 **블록 2는 p마다 다시 실행**한다 (블록 3이 같은 MR(p)로 액추에이터 실제
힘·마운트 하중을 환산). p의 3수준 값 자체는 D16에서 확정.

## 출력 → I1

코너별 휠센터력 `(Fx,Fy,Fz)_i`, 액추에이터 힘 `F_act,i`, **스프링·댐퍼 힘 4개(v0.4 추가)**, 차체 가속도,
서스펜션 스트로크, 시나리오 태그(블록 3 입력).
