# 블록 7 · 리플레이 뷰어 (담당 A — v0.8에서 B→A로 이동, MATLAB → MP4)

**D8 확정(v0.8): 뷰어는 A로 이동했다.** A의 부하가 크므로 **최소판만 필수**로 두고, B는 응력 결과를 I2·I3
형식으로 제공해 뷰어를 돕는다(직접 구현에는 참여하지 않음).

발표용 시각자료. 레이스라인을 따라 차량이 자동 주행하고, 옆에 파라미터 그래프를 동기화해 띄워 "어느 구간에서
무엇이 어떻게 변하는지" 눈으로 확인하는 용도. **분석과 무관한 후처리 블록** — I3·I4를 읽기만 함.

## 필수 vs 선택 (v0.8, 시간 부족 시 선택부터 포기)

- **필수(최소판)**: 트랙 위 차량 마커 주행 + 동기 그래프
- **선택**: 라인 색 응력 연동, 실측 F1 비교 슬라이드, 슬로모 클립 — 시간이 모자라면 **선택부터 포기**
  (`docs/schedule.md` 축소 우선순위 1번)

## 화면 영역 (16:9)

| 영역 | 내용 |
|---|---|
| 좌 60% 트랙맵 | 레이스라인 위 차량 마커(헤딩 회전), 라인 색 = 로어암 응력 또는 누적손상(선택), 코너명·구간 경계 |
| 우 40% 동기 그래프 | v / g-g 다이어그램(궤적 잔상) / 볼조인트 하중 / 핫스팟 응력 + 누적손상 D |
| 하단 | 구간 진행바 + 구간별 손상 막대 |
| 별도 슬라이드(선택) | 실측 F1(FastF1) vs 우리 차 속도 트레이스를 거리축 s에 겹침 + 트랙맵에 두 차 마커 |

## 미리 알아야 할 것

1. **제어기끼리는 고스트카 비교 불가** — 단방향 커플링이라 모든 제어기의 궤적·타이밍이 동일. 차량 마커는 1대,
   제어기 비교는 우측 그래프 색 오버레이로. 실측 F1 vs 우리 차는 차가 달라 타이밍이 다르므로 두 마커 비교가
   의미 있음(선택 기능).
2. **다운샘플링하면 피크 소실** — 시뮬은 kHz급, 영상은 30fps. 그래프는 원본 해상도로 미리 그려두고 커서(세로선)만 이동.
3. **풀랩 실시간은 너무 김** — 풀랩 4–6배속 + 핵심 구간(Eau Rouge 등) 슬로모 클립으로 분리(선택).
4. **구간은 코너 단위** — 공식 3섹터는 너무 굵음. La Source, Eau Rouge-Raidillon, Les Combes, Pouhon,
   Blanchimont, Bus Stop 등으로 정의.
5. **라이브 데모 대신 MP4** — 발표 중 MATLAB 실행은 렌더링 지연·크래시 리스크. `VideoWriter`로 1080p 30fps.

## MATLAB 구현 뼈대

- 색칠된 트랙: `patch`의 `EdgeColor='interp'` (선을 CData로 칠하는 표준 방법)
- 차량: 삼각형 `patch` + `hgtransform`(위치·회전)
- 커서: `xline` 핸들의 `Value`만 갱신
- 루프: 갱신 → `drawnow` → `getframe` → `writeVideo`
