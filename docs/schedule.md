# 작업 순서 (v0.8, 날짜 없음 — 게이트 기반)

D5(v0.8)에 따라 **마감 날짜는 관리하지 않는다.** W1–W7은 주차가 아니라 **순서**다. 각 단계는 앞 단계의 게이트를
통과해야 시작할 수 있다. 결과는 W6에 동결하고 W7은 영상·슬라이드·리허설에 쓴다.

| 단계 | 담당 A (나) | 담당 B | 마일스톤 / 게이트 |
|---|---|---|---|
| W1 | 차량 파라미터·좌표계 확정, 트랙 로드·곡률 계산, FastF1 환경 세팅·세션 선정(D9), 액추에이터 사양 출처(D15) | 하드포인트 표, 환경 확인(COMSOL 버전·Rigid Connector·LiveLink), FBD 미지수·방정식 점검, 로어암 FEA 논문 선정 | I0–I5 포맷·3축 지표 정의 합의, p_min·p_max 산출 착수(D16) |
| W2 | FastF1 Z→고저 z(s), 랩 시뮬(v 프로파일, s→t), 실측 속도 비교 검증, **시나리오 B 프로파일** | FBD 구현 + 손계산 검증 | Spa 랩 v,ax,ay 산출(A/B) + 방법론 검증 **(게이트: 방법론 검증)** |
| W3 | 풀카 State-Space + Passive/Skyhook | COMSOL 형상·메쉬·고유진동수, Rigid Connector 확인, 액추에이터 열 모델 뼈대 | 첫 휠력 시계열(I1) **(게이트: I1)** |
| W4 | LQR + 액추에이터 모델 | 단위하중 해석(**마운트 위치 3수준**), 빔·해석해 검증, 액추에이터 전기-열-구조 해석 | 응력계수 표 + Rth 완성 **(게이트: 응력계수표·Rth)** |
| W5 | 위치 스케줄 LQR(블렌딩), 열 제약 판정 | 응력 지표 `lca_damage()`, 두께 스윕 통합, Fth 전달(I5) | 첫 응력 지표(DEL, R) + **둔감도 게이트** |
| W6 | 공동: p × 시나리오 스윕, 2단계 선정, 로어암 최소 단면 | | 결과 동결 |
| W7 | 공동: 뷰어 최소판 완성, 리플레이 영상, 구조 파트 슬라이드, 응력 결과 파일 보강 | | 발표 (공동 리허설) |

## 게이트 상세

- **W2 게이트 (방법론 검증)**: 랩 시뮬 속도가 FastF1 실측과 제동점/코너 정점에서 맞아야 W3로 진행.
- **W3 게이트 (첫 휠력 시계열 I1)**: 블록 2 출력이 나와야 블록 3(B)이 실데이터로 검증 가능.
- **W4 게이트 (응력계수표·Rth)**: 블록 4a(응력계수)와 4b(Rth)가 둘 다 끝나야 블록 5가 완성됨.
- **W5 게이트 (둔감도 게이트)**: 제어기 간 DEL 차이가 작으면(둔감하면) 스윕 격자·선정 규칙을 재점검.
- **두께 스윕(D11)은 정적 해석이라 W4–W5에 B가 미리 돌려둔다** — 블록 6(A)의 최소 단면 선정을 기다리지 않음.

## 필수 유지 (축소해도 빼면 안 되는 것)

응력 지표 파이프라인, 시나리오 A/B, 3축 트레이드오프, 액추에이터 열연성 자체(멀티피직스 요건, 과제 가점), 뷰어 최소판.

## 시간이 모자랄 때 축소 우선순위 (이 순서로 제거)

1. 뷰어 확장 기능 (응력 연동 색칠, 슬로모 클립) — 최소판(트랙맵+차량마커+동기그래프)만 남김
2. 서킷 확장 포기 (뉘르부르크링·Monza·Hungaroring) — Spa 하나로 끝냄
3. 위치 스케줄 제어를 고정 LQR 2종 비교로 대체
4. 마운트 위치를 3수준 → 2수준으로 축소
5. 최소 단면 스윕을 스트레치로 강등
6. 액추에이터 열 해석을 정상상태 1회로 축소 (과도 해석 생략)
