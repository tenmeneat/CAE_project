## 한 일

- 레포 루트를 그대로 Obsidian 볼트로 쓰도록 `.obsidian/` 설정을 커밋했다. 창 배치처럼 사람마다 바뀌는
  `workspace.json`은 `.gitignore`로 제외했다.
- 이름이 전부 `README.md`라 Obsidian에서 구분이 안 되던 노트를 내용이 드러나는 이름으로 바꿨다(아래 표).
  루트 `README.md`는 GitHub 첫 화면이라 그대로 두고 허브 노트로 쓴다.
- 각 노트 끝에 "연결" 절을 달아 입력·출력 블록, 인터페이스, 관련 결정, 작업 기록을 서로 링크했다.
- 이 작업 기록 폴더와 목차([05-작업기록](../05-작업기록.md))를 새로 만들었다.

## 링크 형식

GitHub에서도 링크가 동작하도록 `[[위키링크]]` 대신 **상대 경로 마크다운 링크**를 쓴다. Obsidian 설정도
마크다운 링크·상대 경로로 맞추고 파일 이름을 바꾸면 링크가 자동으로 갱신되게 했다. 그래프 뷰는 폴더별 색으로
구분된다(작업기록 / docs / matlab / comsol / python·data). 클론한 전체 TUMFTM 저장소
(`data/tracks/racetrack-database/`)는 볼트 검색에서 제외했다.
