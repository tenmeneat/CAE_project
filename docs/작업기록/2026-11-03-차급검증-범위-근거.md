# 2026-11-03 · 차급 검증 판정 범위의 근거 (R컴파운드 μ 1.11–1.25)

← [블록 1 구현](2026-11-03-블록1-구현.md) · [05-작업기록](../05-작업기록.md)

## 배경

Lapmeta 2:43.2 차급 검증에서 역산 μ는 1.174였고, 출처 없이 둔 R컴파운드 범위 1.2–1.5 밖이라 FAIL이었다. 범위를 넓혀
통과시키는 건 끼워 맞추기라 하지 않고, 근거를 먼저 찾았다.

먼저 모델 가정을 하나씩 바꿔 역산 μ가 얼마나 움직이는지 봤다. 구동계 효율 0.85(+0.021), 압축 이득 제거(+0.018),
κv 무시(+0.010), CdA +13%(+0.009), 곡률 평활 5 m(+0.004) — 어느 것도 0.02를 크게 넘지 않아, 판정은 모델 수정이
아니라 범위 근거에 달려 있었다.

## 결정

순정 썸머 μ 1.10(사용자 지정) 대비 R컴파운드 그립 비율을 같은 차 타이어 비교 두 건에서 유도했다.

| 자료 | 내용 | 결과 |
|---|---|---|
| [Tire Rack 2025 Test 4](https://www.tirerack.com/tires/tests/testDisplay.jsp?ttid=345) | BMW M2, 275/35R18, 3.2 km 서킷, 평균 랩 | R컴파운드가 익스트림 썸머보다 0.5–3.1% 빠름 → μ +1.4–9.0% (모델 민감도 0.35) |
| [Car and Driver 2012](https://autos.yahoo.com/monsters-grip-nine-summer-performance-164800060.html) | BMW 328i, 마른 스키드패드 | 익스트림 썸머끼리 0.87–0.91 g → 순정급 썸머와의 차이 0–4.6% |

합쳐서 **+1–14% → μ 1.11–1.25**. 역산 μ 1.174(+6.7%)는 범위 안 → **PASS**. 기록 차량 신고값(340 kW, 1590 kg)으로
돌린 1.145도 범위 안이다. 민감도를 0.5로 잡아도 1.11–1.22로 판정은 같다.

## 한계

- 범위가 넓어 약한 검증이다.
- 랩타임→μ 환산에 모델 자신의 민감도(기울기)를 빌렸다.
- R7 자체 데이터가 없다 (Tire Rack은 A055·A7, R7–A055 차이 0.1–0.2 s는 검색 요약으로만 확인).
- 결과(1.174)를 본 뒤에 범위를 정했다. 범위 자체는 자료에서 기계적으로 계산했다.
