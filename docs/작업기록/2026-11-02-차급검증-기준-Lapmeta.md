# 2026-11-02 · 블록 1 차급 검증 기준 (Lapmeta 2:43.2)

← [I0 데이터 레포 포함](2026-11-02-I0-데이터-레포-포함.md) · [05-작업기록](../05-작업기록.md) · 다음 → [옵시디언 정리](2026-11-03-옵시디언-정리.md)

## 배경

순정 F82 M4의 Spa 랩타임은 BMW 공식값도 잡지 실측도 없다. 그래서 기존의 "GT 파라미터 랩타임이 실측 ±10% 이내"
기준을 쓸 수 없었다.

## 결정

Lapmeta에 올라온 기록을 차량 사양 페이지로 확인해 분류했다.

| 기록 | 차량 | 판단 |
|---|---|---|
| **2:43.2** | F82 M4 + Hoosier R7(순정 사이즈), 456 hp, 1,515 kg, 엔진·공력 개조 없음 | 채택 |
| 2:38.0 | M4 CS 레이스 빌드(640 hp, 슬릭, GT4 공력) | 제외 |

검증은 μ를 맞춰 넣는 게 아니라 **2:43.2를 내는 μ를 역산해 R컴파운드 문헌 범위 안인지 확인**하는 방식이다.
통과하면 μ를 순정 썸머 타이어 값으로 되돌려 시나리오 A 입력을 만든다. 타이어 μ 범위 2종은 D3에 추가됐다.
