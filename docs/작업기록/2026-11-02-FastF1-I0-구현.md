## 1. 세션 선정 (D9)

FastF1 3.9로 Spa 레이스를 시즌별로 조회했다. 정상 랩 = 녹색기, 피트 입출구·1랩 제외.

| 시즌 | 결과 |
|---|---|
| 2019, 2020, 2023–2025 | F1 계정 없이 로드 실패 (FastF1 3.9가 계정 인증을 요구) |
| 2021 | 우천, 정상 랩 20개 → 제외 |
| **2022** | 건조, 전체 792랩 중 정상 랩 629개, 최속 109.354 s → **채택** |

최종 사용 랩은 정확도 플래그와 107% 기준까지 적용한 **613개(드라이버 18명)**. F1 계정 정보는 입력하지 않았고,
스크립트는 계정 프롬프트를 자동으로 건너뛴다. → [03-결정사항](../03-결정사항.md) D9에 기록.

## 2. 처리 방식

위치·차량 스트림 보간 병합 → 속도 적분 거리를 랩 길이로 정규화해 TUMFTM 레이스라인 거리 `s`에 맞춤 →
랩 평균 → z만 주기 평활 스플라인 → 곡률 상호상관으로 출발선 위상 보정. 자세한 단계는
[전처리-FastF1-I0](../../python/fastf1_preprocessing/전처리-FastF1-I0.md).

## 4. 검증 중 고친 문제

1. **출발선 위상차**: FastF1 타이밍 라인과 TUMFTM 첫 점이 16 m 어긋나 있었다 → 곡률 순환 상호상관으로 자동 보정.
2. **CSV 반올림 노이즈**: 소수점 4자리로 쓰면 z를 두 번 미분한 κv에 노이즈가 섞인다 → 6자리로 저장.
3. **이음매 κv 스파이크**: 출발선 보정 때 격자가 둘레를 정확히 나누지 않아 s ≈ 18 m에 가짜 스파이크(0.00314)가
   생겼다 → 격자 간격을 둘레/N으로 맞춰 해결.
4. Z 이상치 랩 필터는 613개 중 하나도 걸러내지 않아 삭제했다.
