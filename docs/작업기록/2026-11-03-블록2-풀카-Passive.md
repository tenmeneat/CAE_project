# 2026-11-03 · 블록 2 풀카 7DOF Passive와 Simulink 물리 모델

← [차급 검증 범위 근거](2026-11-03-차급검증-범위-근거.md) · [05-작업기록](../05-작업기록.md)

## 한 일

- D3의 남은 차량 파라미터를 채웠다. k·c는 직접 정하지 않고 승차 주파수(앞 1.6 / 뒤 1.8 Hz)와 Passive 감쇠비(0.30)에서
  역산한다 — 두 값은 사용자 지정. 타이어 강성 280 N/mm, 비현가 질량 45/50 kg, 관성(동적지수 1, Ixx 500)은 [가정].
  F82 실측은 유료 Michelin SIMIX 데이터셋뿐이다.
- 스태빌라이저: 롤 구배 3.0°/g, 앞 횡하중 이동 비율 0.57([가정])을 정확히 맞추도록 역산 → 휠 기준 앞 16.4 / 뒤 0.65 N/mm.
- `build_state_space.m`: 7DOF A, B (상태 14, 입력 = 액추에이터 4 + 노면 4 + ax, ay). 휠 기준 강성을 고정해 A, B는
  마운트 위치 p와 무관 — p는 W4 포화·스트로크 한계로만 들어온다.
- Simulink `fullcar_7dof.slx`를 **물리 부품별 서브시스템**(Load Transfer, Corner ×4, Anti-roll Bar, Sprung Body,
  Controller)으로 구현하고 **단방향 타이어 접촉** `Fz = max(0, ·)`을 넣었다. 설계안 v0.8의 State-Space 블록 방식을 대체.
  `build_fullcar_model.m`이 원본이고, 루트는 Goto/From 태그로 연결해 배선을 정리했다.
- `make_spa_inputs.m`: 블록 1 출력 → 입력. 노면 = 고저 + ISO 8608(좌/우 시드), 후륜은 시간 지연 대신 거리 s−b.

## 경과와 판단

- 처음 피치 관성 2,000 kg·m²로는 피치 모드가 2.1 Hz로 높았다(동적지수 0.70). 동적지수 1로 바꿔 앞뒤 승차 모드를
  분리했고, 그 덕에 승차 주파수 역산을 정확히 검증할 수 있게 됐다.
- 스프링만으로는 롤 구배 3.8°/g, 앞 비율 0.46(후륜 쪽 하중 이동이 더 큼)이라 스태빌라이저를 넣었다.
- 처음엔 설계안대로 State-Space 블록 하나로 만들었는데, 사용자가 물리가 보이는 모델을 원했다. 같은 시점에 B-C급
  노면에서 선형 타이어 하중이 음수(A 약 1%)로 나와, 물리 서브시스템 안에서 `max(0, ·)`로 이탈을 처리하는 쪽으로
  바꿨다. 대수루프는 상태를 적분기 출력으로 두는 구조로 피했고, LQR용 A, B와의 일치는 linmod로 보장한다.
- 피치 최대 약 9°는 노면 경사(Spa 최대 8.8°)를 따라간 것이라 문제가 아니다.
- 이 MATLAB(R2026a, 한국어)에서 From 블록 아이콘이 `-T-`로만 보여 태그를 블록 주석으로 표시했다.
