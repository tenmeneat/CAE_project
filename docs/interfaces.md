# 인터페이스 (파일 계약)

2인 병렬 작업의 핵심. **여기 포맷부터 합의하고, 더미 데이터로 양쪽이 독립 개발한다.** 아래 스키마는 설계안 9장을
그대로 따르되, 실제 필드명/타입은 구현 시작 시 확정해서 이 문서를 갱신할 것 (지금은 초안).

| ID | 방향 | 파일 / 함수 | 내용 |
|---|---|---|---|
| I0 | Python → A | `fastf1_<track>.csv` | `s, x, y, z, v, throttle, brake` (여러 랩 평균, s 정렬 완료). A 내부 전처리용 |
| I1 | A → B | `wheel_forces_<track>_<ctrl>.mat` | `t`, 코너별 휠센터력 `(Fx, Fy, Fz)` 4×3, 액추에이터 힘 4개, 제어기 태그 |
| I2 | B → A | `[D, Dsec, sig] = lca_damage(wf)` | 입력 I1 구조체 → 랩당 손상, 구간별 손상, 핫스팟 응력 시계열. A가 스윕 루프에서 호출 |
| I3 | A·B → 뷰어 | `replay_<track>_<ctrl>.mat` | `t, s, x, y, psi, v, ax, ay, F_BJ, sigma_hot, D_cum` |
| C | 블록4 → 블록5 | 응력계수 표 | 단위하중(볼조인트 Fx,Fy,Fz 각 1N, 액추에이터 마운트 1N)별 핫스팟 응력텐서 6성분. Q/R을 바꿔도 재해석 불필요 |

## 공통 규약 (W1에 확정해야 함)

- **단위**: SI
- **좌표계**: ISO 8855 (x 전방, y 좌측, z 상방)
- **코너 순서**: FL → FR → RL → RR
- **하중 부호**: 로어암에 작용하는 힘 기준으로 통일 (작용/반작용 혼동 주의)

## 스키마 확정 체크리스트

- [ ] I0 CSV 컬럼 순서/헤더 확정
- [ ] I1 `.mat` 구조체 필드명 확정 (MATLAB `struct` 권장 — 필드 접근 명확)
- [ ] `lca_damage()` 함수 시그니처 확정 (입력 구조체 필드, 출력 3개 순서)
- [ ] I3 리플레이 뷰어가 기대하는 샘플링 주기 확정 (원본 kHz급 vs 다운샘플 — 커서만 이동, 그래프는 원본 해상도 유지)

더미 데이터로 먼저 I1/I3 포맷을 고정하고, 블록 2(A)와 블록 4/5(B)는 서로의 완성을 기다리지 않고 병렬 개발한다.
