## 연구 질문

하나의 하드웨어(액추에이터 마운트 위치)로 스포츠 주행의 접지와 컴포트 주행의 승차감을 지키면서, 액추에이터
부하와 로어암 응력을 어디까지 줄일 수 있는가?

세부적으로 이 프로젝트가 답하는 질문은 3개:
1. **(주 질문)** 어떤 마운트 위치와 모드별 제어 설정이 두 시나리오의 3축을 가장 잘 양립시키는가? (선정 기준: 5.4절 2단계 규칙)
2. 그 설정을 구현하려면 액추에이터가 최소 어느 정도 성능이어야 하는가? (열적 한계 포함)
3. 그 하중 환경에서 허용 응력을 만족하는 로어암 최소 단면은 얼마인가? (메인 결과, D11)

## 시나리오 / 설계 변수 구조

실차는 **하드웨어는 하나**, 주행 모드는 **소프트웨어로 전환**한다 (F82 M4의 EDC Comfort/Sport/Sport+처럼).

| 층위 | 무엇 | 바뀌는 시점 |
|---|---|---|
| 하드웨어 (바깥 루프) | 프런트 액추에이터 마운트 위치 p (로어암 위 3수준: 바깥/중간/안쪽). 리어는 패키징 기준값으로 고정(D18) | 설계 단계에서 1개 결정 |
| 운전 모드 (시나리오) | A 스포츠 / B 컴포트 | 주행 중 전환 |
| 제어 튜닝 (안쪽 루프) | 모드별 LQR 가중치, 위치 스케줄 | 모드마다 다름 |

| | 시나리오 A · 스포츠 | 시나리오 B · 컴포트 |
|---|---|---|
| 경로·속도 | Spa 레이스라인, 한계 주행(마찰원 한계) | Spa 중심선, 가속도 상한 \|ay\|≤0.4g, \|ax\|≤0.3g (가정, D17) |
| 노면 | 고저 + ISO 8608 B-C급 | 고저 + ISO 8608 B-C급 |
| 3축 | 접지 - 액추에이터 - 암 하중 | 승차감 - 액추에이터 - 암 하중 |
| 제약 | 스트로크·포화·열·정적 안전계수 (승차감은 보고만) | 접지·스트로크·포화·열 (안전상 접지 제약 유지) |
| 역할 | 최소 단면을 지배 (설계 하중) | 승차감 제약 판정. 암 하중은 확인용(피로한도 이하일 가능성 높음) |

**세부 시나리오는 늘리지 않는다.** 결론은 "마운트 위치 p\* 1개 + 모드별 제어 설정 + 최소 단면"이다.

## 반드시 알고 시작할 함정 2개 (v0.3과 동일)

1. **7자유도 풀카는 수직력만 나온다.** 로어암 하중의 주범은 제동 Fx·선회 Fy인데 7DOF는 수직만 다룸.
   → 가감속·횡가속 하중이동을 pitch/roll 모멘트로 얹고, 타이어 Fx/Fy는 Fz 비례로 준정적 분배.
2. **"액티브 서스펜션 = 로어암 응력 감소"는 보장되지 않는다.** Hedrick-Butsuen invariant point [R5] 때문에
   휠홉 주파수에서는 어떤 서스펜션 힘으로도 차체 가속도를 바꿀 수 없다. 승차감 튜닝이 오히려 타이어 동하중·로어암
   굽힘하중을 키울 수 있음 → 이 불확실성 자체가 연구질문.

## 파이프라인 (블록 1–7)

계산(1–6)은 파일(인터페이스 I0–I5)로만 데이터를 주고받고, 블록 7은 결과를 읽기만 한다.

```
데이터+Python 전처리 (TUMFTM(2D) + FastF1(z,v))
        │ I0
        ▼
1. 랩 시뮬레이션 (MATLAB, A)          시나리오 A/B → v, ax, ay, z
        │ (내부, v/ax/ay/z)
        ▼
2. 풀카 7DOF + 액티브 제어 (Simulink, A)    Passive/Skyhook/LQR/스케줄, p별로 재실행
        │ I1: wheel_forces_<track>_<scn>_<ctrl>.mat
        ▼
3. 휠력 → 로어암 하중 (MATLAB, B)      하드포인트 FBD + 모선비 MR(p) 환산
        │ F_LCA(t)
        ├─────────────────────────────┐
        ▼                              ▼
4a. COMSOL 로어암 구조 (B)       4b. COMSOL 액추에이터 전기-열-구조 (B)
    응력계수 C, 고유진동수            열적 연속 힘 한계 F_th
        │ C                              │ I5: act_thermal_<act>.mat (Rth, Fth 등)
        ▼                              │
5. 응력 중첩 → 응력 지표 (MATLAB, B)  ◄──┘
   res = lca_damage(wf)  → D, DEL, sigma_peak, Dsec, sig, parts
        │ I2
        ▼
6. p × 시나리오 × 제어 스윕 + 2단계 선정 (MATLAB, A)   약 300–480회 조합
   Q/R 변경 → 2부터 재실행 (COMSOL 재해석 불필요)
        │ I4: sweep_results_<track>.mat
        ▼
7. 리플레이 뷰어 (MATLAB → MP4, A)    I3·I4를 읽기만 함, 발표용
```

Q/R 가중치만 바뀌면 블록 2→3→5만 재실행하면 되고 COMSOL(4a) 재해석은 필요 없다. 단, 블록 4a(로어암)는 형상·두께가
바뀌면, 블록 4b(액추에이터 열)는 액추에이터 사양이 바뀌면 다시 돌려야 한다.

## 평가 지표 (5장)

최적은 한 점이 아니라 **"제약을 모두 만족하는 후보 중 액추에이터 부담 대비 로어암 응력 이득이 가장 큰 설정"**으로
정의한다.

| 축 | 지표 | 계산 위치 |
|---|---|---|
| 접지 (A 주, B 제약) | 타이어 동하중 RMS (코너별) | 블록 2 출력, A |
| 승차감 (B 주, A 보고) | 운전석 수직 가속도의 ISO 2631-1 Wk 가중 RMS | 블록 2 출력, A |
| 액추에이터 부담 | RMS 힘, 피크 힘, 평균 소비전력, 열 한계 여유 F_rms/F_th | 블록 2 출력 + I5, A |
| 로어암 응력 | 핫스팟 피크 응력, 등가응력진폭(DEL), Passive 대비 손상비 R | 블록 5, B (I2) |

### 제약 (만족 못 하면 후보에서 제외, 5.2절)

접지(B, Passive 대비 RMS 이하), 승차감(B, Passive 대비 허용수준 이내), 서스펜션 스트로크(한계 이내), 액추에이터
(포화 한도·지속시간 상한), 액추에이터 열(F_rms ≤ F_th), 로어암 정적 안전계수(핫스팟 피크응력 ≤ 허용응력).

### 상대 손상 지표 (5.3절)

절대 수명 N 대신 Passive 대비 비율을 보고한다.

```
D = 2*sigma_f'^(-m) * sum(ni * sigma_ar_i^m)
R = D_ctrl / D_passive
sigma_DEL = (sum(ni*sigma_ar_i^m) / Neq)^(1/m)
sigma_DEL,ctrl / sigma_DEL,passive = R^(1/m)
```

랩당 절대 손상 D는 숫자가 매우 작아 직관이 안 되므로 **보고서의 주 지표로 쓰지 않는다** — R과 DEL을 쓴다.

### 최적 선정 규칙 (2단계, 5.4절)

1. **1단계·모드별 제어 설정**: 마운트 위치 p마다, 시나리오별로 ε-제약(해당 시나리오 제약 모두 만족 + 액추에이터
   예산 Pmax 이하) 후보 중 로어암 DEL이 최소인 설정을 고른다.
2. **2단계·마운트 위치 p\***: 두 시나리오 모두 1단계 선정을 만족하는 p 중, 시나리오 A의 로어암 DEL이 최소인 p를
   고른다. 모드별 최적 위치가 다르면 그 차이 자체가 결과(하드웨어 1개의 타협점).
