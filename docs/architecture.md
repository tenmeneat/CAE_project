# 아키텍처 요약

원본 설계안: [`design/CAE_design_v0.2.pdf`](design/CAE_design_v0.2.pdf) (v0.2, 2026-10-27). 이 문서는 그 요약이며,
세부 수식·근거는 반드시 원본을 참고할 것.

## 연구 질문

고속 서킷 주행에서 액티브 서스펜션 제어 전략(승차감 우선 / 접지 우선 / 위치 스케줄)이 로어암(LCA) 피로손상에
어떤 영향을 주는가? 승차감과 구조 내구 사이의 파레토는 어떻게 생겼는가?

## 파이프라인 (블록 1–7)

계산(1–6)과 시각화(7)는 완전히 분리되고, 블록 간에는 오직 파일(인터페이스 I0–I3, [`interfaces.md`](interfaces.md))로만
데이터를 주고받는다.

```
1. 랩 시뮬레이션 (MATLAB, 담당 A)
   서킷 곡률·고저 → v, ax, ay
        │ (내부)
        ▼
2. 풀카 7DOF + 액티브 제어 (Simulink, 담당 A)
   Passive / Skyhook / LQR / 스케줄
        │ I1: wheel_forces_<track>_<ctrl>.mat
        ▼
3. 휠력 → 로어암 하중 (MATLAB, 담당 B)
   하드포인트 준정적 FBD
        │ (내부)
        ▼
4. 로어암 단위하중 해석 (COMSOL, 담당 B)
   응력계수 + 고유진동수  ──┐
        │ C: 응력계수 표    │ Q/R만 바꿀 때는 2→3→5만 재실행,
        ▼                  │ COMSOL 재해석 불필요
5. 응력 중첩 → 피로 (MATLAB, 담당 B)
   Rainflow + Goodman + Miner
        │ I2: [D, Dsec, sig] = lca_damage(wf)
        ▼
6. 가중치 스윕 · 스케줄 (MATLAB, 담당 A)
   승차감 vs 피로 파레토  ──→ 2로 피드백 (Q/R 스윕 루프)
        │ I3: replay_<track>_<ctrl>.mat
        ▼
7. 리플레이 뷰어 (MATLAB → MP4, 담당 B 주도)
   레이스라인 자동 주행 + 동기 그래프 (발표용, 분석과 무관)
```

## 핵심 설계 결정

- **풀카 7자유도 + 액티브 제어 + 구조 해석**까지 하나의 파이프라인으로 연결 (쿼터카 대비 차별화)
- 평가 기준은 정적 피크응력이 아니라 **피로손상(랩당)**
- 하중 입력은 임의 시나리오가 아니라 **실제 서킷 듀티사이클** (TUMFTM 트랙 형상 + FastF1 실측 고저/검증)
- 메인 기여 후보: 구간별로 제어 가중치를 바꾸는 **위치 스케줄 제어**

## 반드시 알고 있어야 할 함정 2개

1. **7자유도 풀카는 수직력만 나온다.** 로어암 하중의 주범은 제동 Fx·선회 Fy인데 7DOF는 수직만 다룸.
   → 가감속·횡가속 하중이동을 pitch/roll 모멘트로 얹고, 타이어 Fx/Fy는 Fz 비례로 준정적 분배 (블록 2, 4.2절).
2. **"액티브 서스펜션 = 로어암 응력 감소"는 보장되지 않는다.** 휠홉 주파수에서는 Hedrick–Butsuen invariant point에
   의해 어떤 서스펜션 힘으로도 차체 가속도를 바꿀 수 없음 [R5]. 승차감 튜닝이 오히려 타이어 동하중·로어암 굽힘하중을
   키울 수 있다. → 이 불확실성 자체가 연구질문이므로, 결과가 반직관적으로 나와도 프로젝트는 성립한다.

## 데이터 소스

| 소스 | 용도 | 비고 |
|---|---|---|
| [TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database) (R1) | 트랙 중심선·폭·레이스라인 (2D, 수평 곡률) | LGPL-3.0, F1·DTM 20개+ 서킷 |
| [FastF1](https://docs.fastf1.dev) (R8, R9) | 실측 고저(Z), 랩 시뮬 방법론 검증, 발표용 속도 비교 | 위치 X/Y/Z ~4.5Hz, 하중 입력으로 직접 쓰지 않음(차급 불일치) |

역할 분리: 수평 곡률 κ(s)는 TUMFTM 레이스라인, 고저 z(s)와 검증은 FastF1. 두 데이터는 좌표계가 달라 **출발선 기준
거리 s**로 정렬한다.

## 서킷

Spa-Francorchamps를 기본으로 함 (고저차 102.2 m, Eau Rouge 압축 구간 → 결정적 대하중 이벤트). 일정 여유가 있으면
Monza(고속 강제동), Hungaroring(저중속 연속 코너)과 비교.
