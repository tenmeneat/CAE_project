# 미결정 사항 트래커 (설계안 11장)

상태: `OPEN` = 아직 안 정함 / `PROPOSED` = 설계안의 추천값으로 잠정 채택, 팀 확인 필요 / `DONE` = 확정.

| ID | 안건 | 상태 | 추천 / 메모 |
|---|---|---|---|
| D1 | 서스펜션 형식 | PROPOSED | 더블위시본(스프링·액추에이터 로어암 마운트). 로어암 직접 굽힘하중 → 제어-구조 커플링 명확. 블록 3 세부 설계(FBD 미지수·방정식 구성)의 전제이므로 **이게 안 정해지면 블록 3을 못 짠다** |
| D2 | 메인 기여 | PROPOSED | 위치 스케줄 제어 채택. 대안: 일정 빠듯하면 고정 LQR 2종 비교로 축소 |
| D3 | 차량 파라미터 출처 | OPEN | 고성능 로드카 또는 GT급 문헌값. 질량·관성·CG 높이·스프링·타이어 강성 — 출처 확정 필요 |
| D4 | 로어암 재질 | OPEN | 단조 알루미늄 vs 강판. **S-N 데이터를 실제로 확보할 수 있는 쪽으로 결정** (피로 블록의 전제) |
| D5 | 마감일 | OPEN | 확정 후 10장 일정표(W1–W7)에 날짜 매핑 |
| D6 | 고저 프로파일 근사 방법 | DONE | FastF1 실측 Z 사용. 평활 강도만 민감도 파라미터로 유지 |
| D7 | COMSOL 라이선스 확인 | OPEN | Structural Mechanics 모듈, LiveLink for MATLAB 유무. 선배 팀이 라이선스(난류 모듈)·구버전(5.2) 제약을 겪은 사례 있음 — **블록 4 시작 전에 반드시 확인** |
| D8 | A/B 담당자 배정 | OPEN | 담당 A = 동역학·제어(블록 1·2·6), 담당 B = 구조·내구(블록 3·4·5·7) |
| D9 | FastF1 대상 세션 | OPEN | 예선 최속랩 vs 레이스 여러 랩. 고저 평균엔 여러 랩이 유리 |

## 당장 막는 순서로 보면

1. **D7 (COMSOL 라이선스)** — 블록 4를 시작할 수 있는지 자체를 결정함. 제일 먼저 확인.
2. **D1 (서스펜션 형식)** — 블록 3 FBD 설계의 전제. PROPOSED 값(더블위시본)으로 일단 진행하되 팀 확인 필수.
3. **D4 (로어암 재질)** — S-N 데이터 확보 가능 여부가 선행 조건이라 리서치가 먼저 필요.
4. **D8 (담당자 배정)** — 병렬 작업 시작 조건.
5. D3, D5, D9는 각 블록 구현 중간에 채워도 파이프라인 구조 자체엔 영향 없음.
