# 인터페이스 (파일 계약, v0.8)

2인 병렬 작업의 핵심. **W1에 포맷부터 합의하고 더미 데이터로 양쪽이 독립 개발한다.** v0.4에서 I1·I2를 확장,
v0.5에서 I5를 추가, v0.7에서 I4를 추가했다.

| ID | 방향 | 파일 / 함수 | 내용 |
|---|---|---|---|
| I0 | Python → A | `fastf1_<track>.csv` | `s[m], x[m], y[m], z[m], v[m/s], throttle[0–1], brake[0–1]` (여러 랩 평균, s 정렬 완료). `s`는 TUMFTM 레이스라인 기준, `x,y`는 FastF1 좌표계. `brake`는 제동 중인 랩의 비율. A 내부 전처리용 |

| I5 | B → A | `act_thermal_<act>.mat` | `Kf, Rcoil`, 열저항 `Rth`, 온도 한계 `Tlim`, 열적 연속 힘 한계 `Fth`, 최대 열응력. A가 블록 6에서 `F_rms ≤ Fth` 판정 |
| C | 블록4a → 블록5 | 응력계수 표 | 단위하중(볼조인트 Fx,Fy,Fz 각 1N, 액추에이터 마운트 1N)별 핫스팟 응력텐서 6성분. **마운트 위치 p별로 반복**(약 9–16회 정적 해석) |

## 공통 규약 (W1 확정)

- **단위**: SI
- **좌표계**: ISO 8855 (x 전방, y 좌측, z 상방)
- **코너 순서**: FL → FR → RL → RR
- **하중 부호**: 로어암에 작용하는 힘 기준으로 통일
- **시나리오 태그**: I0 이후 모든 파일에 `<scn>` (A/B) 태그를 붙인다

## I1 스키마 (초안, 2026-11-03 — B 합의 대기)

`export_i1.m`(블록 2)이 `outputs/i1/wheel_forces_spa_<A|B>_<passive|skyhook|lqr>.mat`를 쓴다. `.mat`은 git 제외라 B는
MATLAB에서 `export_i1()`을 돌려 만든다 (6개, 약 30 s, 약 450 MB). 1 ms 균일, SI, ISO 8855, 코너 순서 FL FR RL RR.

| 필드 | 크기 | 내용 |
|---|---|---|
| `t` | N×1 | 시간 [s] |
| `F_wc` | N×4×3 | 타이어가 바퀴에 주는 힘 `[Fx Fy Fz]`. **접지점 힘**이고 휠센터로 옮길 때의 `Fx·r` 모멘트는 미포함. Fz는 단방향 접촉(정적 포함, ≥ 0). Fx·Fy는 총 힘을 Fz 비례로 나눔 — ΣFy = m·ay, ΣFx = m·ax + 항력 + 경사 중력, **구동(ΣFx > 0)은 후륜만** |
| `F_act`, `F_spring`, `F_damper`, `F_arb` | N×4 | **휠 기준** 힘, + = 서스펜션을 늘림(차체를 밀어 올림). 스프링은 정적 하중 m_c·g 포함. 액추에이터·스프링 마운트 기준 환산(÷MR(p))은 블록 3 |
| `d`, `d_dot` | N×4 | 서스펜션 변위·속도 z_b − z_u (− = 압축) |
| `a_u` | N×4 | 비현가 질량 절대 수직 가속도. 너클 수직 평형 `Fz − (F_spring + F_damper + F_act + F_arb) − m_u·g = m_u·a_u`가 1e-10 N 수준으로 성립 |
| `a_body` | N×3 | 차체 절대 가속도 `[z̈s θ̈ φ̈]` |
| `mu_use` | N×4 | 마찰 사용률 √(Fx²+Fy²)/Fz (Fz < 1 N이면 NaN). 동적 하중 감소 순간 블록 1 한계(1.32)를 넘는 구간이 있음 — 자르지 않음 |
| `metrics` | struct | 3축 지표 (`fullcar_metrics`) |
| `meta` | struct | `track, scenario, ctrl, Kfb, m_u, m_c, mount_p`(지금은 NaN — 포화 없음, A·B는 p와 무관), `created, note` |

B에 확인할 것: 접지점 힘 vs 휠센터 힘+모멘트, 후륜 구동 분배, 마찰 사용률 > 한계 구간 처리, 1 ms 샘플링(용량).

## 의존성 메모

- 블록 3(B)은 I1을 받아 **모선비 MR(p)**로 액추에이터 실제 힘·마운트 하중을 환산한다. 블록 2(A)는 p마다 다시
  실행해야 하고, 리어는 고정 MR_rear를 쓴다(D18).
- 블록 5(B)의 `lca_damage()`는 블록 4a의 응력계수 표 C(p별)와 블록 1-3의 F_LCA(t)를 합쳐 응력 지표를 낸다.
- 블록 6(A)은 I2(B)와 I5(B)를 둘 다 소비해서 제약 판정 + 2단계 선정을 수행한다 — **B가 두 인터페이스를 모두
  먼저 안정화해야 A의 스윕이 막히지 않는다.**
